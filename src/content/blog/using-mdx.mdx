This project uses standard Markdown content for the blog, which keeps the site lightweight and avoids the extra MDX initialization cost during development.

## Why this format?

Markdown keeps the content simple to author, easy to maintain, and avoids the extra build-time work that comes with MDX support.

## What this means for the site

You can still write rich blog posts with headings, lists, links, and imagery without requiring the MDX integration to be active.
